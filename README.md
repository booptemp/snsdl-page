# snsdl-page

[SNSDownloader1](https://github.com/booptemp/SNSDownloader1)（非公開）の iPhone 用ページを GitHub Pages で公開するためのリポジトリ。

- `index.html` は SNSDownloader1 の `docs/index.html` のコピー。秘密情報は含みません
- ページは利用者が入力した GitHub トークンで SNSDownloader1 の Actions を呼び出し、取得結果を表示します
- 更新するときは SNSDownloader1 側の `docs/index.html` を書き換えてからここにコピーします
